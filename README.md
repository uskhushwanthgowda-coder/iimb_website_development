# Personal Portfolio — U.S. Khushwanth Gowda

A refined, minimal, and personal portfolio website built with **HTML5** and **CSS3** (pure code, zero JavaScript, zero frameworks).

---

## 📁 File Structure

```text
WEB/
├── index.html          # Page 1: Home ("Still Figuring It Out")
├── about.html          # Page 2: About Me ("A Little About the Person")
├── education.html      # Page 3: Education ("The Learning Curve")
```

## 🎨 Creative & Modern Palette System

| Color Name | Hex Code | Role & Usage |
| :--- | :--- | :--- |
| **Soft Parchment** | `#F6F1E8` | Primary page canvas, warm tactile background |
| **Deep Ocean** | `#172B3A` | Main headings, navigation, brand mark, flagship cards, footer |
| **Fresh Sage** | `#A3AE91` | Subtle section backgrounds, tags, borders, secondary details |
| **Burnt Coral** | `#D47755` | Selected buttons, links, active navigation indicator, key highlights |
| **Golden Mustard** | `#E6C878` | Used very sparingly for small decorative accents & indicators |
| **Graphite** | `#343A40` | High-contrast, readable, sophisticated main body text |

---

## 🔤 Typography

Imported directly via Google Fonts in the `<head>` of all HTML documents:
- **Playfair Display**: Editorial serif for expressive headlines and quotes.
- **DM Sans**: High-legibility grotesque sans for body copy and paragraphs.
- **Manrope**: Modern geometric sans for navigation, labels, and category eyebrows.
- **Space Grotesk**: Monospace/tabular numerals for dates, scores, and statistics.
